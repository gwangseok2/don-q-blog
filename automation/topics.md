# 초안 주제 큐

`Draft post` 워크플로가 실행될 때마다 맨 위의 미완료 항목(`- [ ]`) 하나를 가져가 초안 PR을 만듭니다.
처리된 항목은 자동으로 `- [x] ... → slug (날짜)`로 바뀝니다.
미완료 항목이 없으면 Claude가 최근 이슈를 조사해서 주제를 직접 고릅니다.

형식: `- [ ] 주제 | 카테고리(선택) | 메모(선택)`

자동 작성 가능 카테고리: `market-analysis`, `stock-analysis`, `news-issue`, `stock-tip`, `home-tip`, `common-tip`
(맛집·일상·여행·매매일지는 직접 경험이 필요하므로 자동 작성 대상에서 제외)

예시:
- `- [ ] 브로드컴(AVGO) 최신 분기 실적 분석 | stock-analysis | AI ASIC 매출 비중 강조`
- `- [ ] 2027년 달라지는 청약 제도 정리 | home-tip`
